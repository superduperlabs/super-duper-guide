## Reporting a vulnerability

**Do not** open public GitHub issues for security vulnerabilities.

Report privately via GitHub **Private vulnerability reporting** (Security tab) or contact the maintainers listed in the repo.

We aim to acknowledge within 3 business days and provide a remediation plan within 10 business days.
