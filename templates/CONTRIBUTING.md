# Contributing

Thanks for contributing to this Super Duper App.

## Setup

```bash
pnpm install
pnpm -r typecheck
pnpm test
pnpm build
```

## Pull requests

- Keep PRs focused.
- Run all quality gates before submitting.
- Update `brain.md` and README when behavior changes.
- Every bug fix should include a regression test where practical.

## Docs

- [brain.md](./brain.md) — what's built
- [AGENTS.md](./AGENTS.md) — agent conventions
- [Super Duper Guide](https://github.com/superduperlabs/super-duper-guide) — family-wide patterns

Be respectful. See project maintainers for questions.
